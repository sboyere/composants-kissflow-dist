            Download / open the manual
            Key functions
            Find a design
            1. Type a reference or pallet code in the search box (top bar). Press Enter to open the first result.
            2. Narrow the list with the owner and status filters, and in the List tab with components, types and patterns.
            3. Click a row to open the design in 3D.
            Create or change a design (FG mode)
            1. Menu › New Reference, or open an existing reference.
            2. Left panel Build sequence: add components on top, click one to edit it, use ↑ ↓ to reorder, pick the pallet at the bottom.
            3. Securing: straps, corners, stretch wrap, plastic cover.
            4. Check the drawing in the Drawing tab.
            Save and statuses
            1. Menu › Save Draft = work in progress. Menu › Save Reference = For Review.
            2. Statuses: Draft → For Review → Approved → In Production. Check Component = a component of the design was changed.
            3. Any change sends the design back to Draft. Every step is in the History (Library tab).
            Approve and release
            1. Click Test Export and check the JPG + PDF in the exports folder.
            2. Library tab › Approve (a warning lists components that are not approved yet).
            3. Export to Production: files go to Production data, status becomes In Production.
            Batch check (team review)
            1. Filter the list (e.g. status For Review).
            2. Menu › Batch check: one PDF page per reference, 3D design left, original drawing right.
            3. The PDF is saved in the Check folder; tick OK / To change on paper.
            Components and pallets (Component mode)
            1. Click Component mode under the Menu.
            2. Pick a component in the right list; edit name, material, weight, item number, dimensions, colour, transparency, corner type.
            3. Pallets: length, width, height, 2 or 4 entries, wood or plastic.
            4. Save for Review → Approve. Designs using a changed component get Check Component.
            5. Snapshot saves the picture in the Components folder.
            Sandbox and settings
            1. At sign-in choose Sandbox (default, test copy) or the Production database.
            2. In the Sandbox everything works, but nothing reaches production; exports go to the Sandbox folder and PDFs are marked SANDBOX.
            3. Click your name (top bar) for User settings: preferred language and database.
            3D view
            1. View: Iso, Front, Side, Top. Drag to rotate, scroll to zoom.
            2. Explode: pull the layers apart (shop-floor view).
            3. Labels EN / FR / both / off, Dimensions on/off. The top-view box shows the reel pattern.
            Database and backups
            1. Start the app with Start_Pallet3d.bat: every save goes straight into pallet3d_db.json.
            2. The last 30 versions are kept in the backup folder.
            3. Menu › Download Database: connection info, reconnect, download a copy, reset the sandbox.
